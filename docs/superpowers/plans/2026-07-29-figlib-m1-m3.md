# figlib M1–M3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A custom SVG emitter for research-grade math figures, proven by recreating Needham Fig [9] and gated by numerical/mechanical/readback checks.

**Architecture:** Figure programs (`CLAIM → compute() → Scene → render → gates`). Scene graph of typed primitives in math coordinates; semantic styling (content/construction/annotation/frame roles); ziamath for math labels with exact bboxes; cairosvg rasterization for gates.

**Tech Stack:** Python 3.12, uv, numpy/scipy, ziamath/ziafont, cairosvg, pytest.

## Global Constraints

- Package layout: `src/figlib/` (uv lib layout). Figures in `figures/`, tests in `tests/`.
- Env quirks (this machine): `SSL_CERT_FILE=<scratchpad>/ca-bundle.pem` for any `uv add` (corporate TLS proxy); `DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib` for anything importing cairosvg. A `Makefile` encodes these.
- Geometry always in math coordinates; only `layout.py` maps to canvas. No primitive stores canvas coords.
- Style by semantic role only — primitives never carry raw stroke settings.
- Run tests: `make test` (wraps `uv run pytest`).

### Task 1: Style + scene primitives + minimal SVG emission

**Files:** Create `src/figlib/style.py`, `src/figlib/scene.py`, `src/figlib/render.py`, `Makefile`, `tests/test_render.py`

**Interfaces (produced):**
- `style.Role` enum: `CONTENT, CONSTRUCTION, ANNOTATION, FRAME, ACCENT1, ACCENT2, MUTED`
- `style.Style` dataclass resolving Role → stroke/dash/width/color; `DEFAULT_STYLE` (house style)
- `scene.Curve(pts: np.ndarray (N,2), role, closed=False)`, `scene.Vector(tail, tip, role)`, `scene.Point(xy, role, filled=True)`, `scene.MathLabel(latex: str, anchor_xy, size_pt=11, role, ha='left', va='baseline')`, `scene.RightAngleMark(corner, dir1, dir2, size)`, `scene.AngleMark(center, dir1, dir2, radius, label=None)`, `scene.Scene(items: list, xlim, ylim)` (xlim/ylim optional → auto from extents)
- `render.to_svg(scene, style=DEFAULT_STYLE, width_px=900) -> str`; `render.save(scene, path_stem)` writes `.svg` + `.png`

Steps: write failing test (a Scene with one Curve + one Vector + one MathLabel emits SVG containing `<path`, an arrowhead marker, and a `<g` for the label; PNG file is nonempty) → implement → pass → commit.

### Task 2: Typeset module (ziamath wrapper)

**Files:** Create `src/figlib/typeset.py`, `tests/test_typeset.py`

**Interfaces:** `typeset.render_math(latex, size_pt) -> TypesetLabel` with `.svg_group: str` (translated `<g>`), `.width_pt, .height_pt, .depth_pt`. Used by render for MathLabel and by gates for exact bboxes.

Steps: failing test (`render_math(r"e^{i\theta}", 11)` gives positive width/height and `<path` content) → implement with ziamath `Latex(...)`/`getsize()` → pass → commit.

### Task 3: Layout (math→canvas mapping, extents, margins)

**Files:** Create `src/figlib/layout.py`, `tests/test_layout.py`

**Interfaces:** `layout.Transform(scene, width_px, pad_frac=0.06)` with `.to_canvas(xy)->(px,py)` (equal aspect, y-flip), `.scale`, `.canvas_w, .canvas_h`; `layout.scene_extents(scene) -> (xlim, ylim)` including label bboxes (via typeset metrics) and vector tips.

Steps: failing tests (round-trip a point; extents include a label's box; equal aspect preserved) → implement → pass → commit. Refactor render.to_svg to use Transform.

### Task 4: Geometry for Fig 9

**Files:** Create `src/figlib/geometry.py`, `tests/test_geometry.py`

**Interfaces:** `geometry.exp_partial_sums(z: complex, n_terms) -> np.ndarray (n_terms+1, 2)` — cumulative sums of z^k/k! as 2D points starting at 0.

Steps: failing test (partial sums for z=iθ converge to `exp(iθ)` within 1e-9 for n=25; for real z the chain is collinear on the x-axis) → implement → pass → commit.

### Task 5: Mechanical gate

**Files:** Create `src/figlib/gates.py`, `tests/test_gates.py`

**Interfaces:** `gates.mechanical(scene, style) -> list[Diagnostic]` where `Diagnostic(kind: 'label-collision'|'clipped'|'low-ink', detail: str)`. Uses layout extents + typeset bboxes. `gates.numerical(assert_fn)` runs the figure's assertions capturing failures as Diagnostics.

Steps: failing tests (two deliberately overlapping labels → collision diagnostic; label outside xlim → clipped; clean scene → empty list) → implement (rect-overlap on canvas-space label boxes; clip = bbox outside canvas) → pass → commit.

### Task 6: Figure program contract + runner

**Files:** Create `src/figlib/program.py`, `figures/fig09_euler_spiral.py`, `tests/test_program.py`

**Interfaces:** `program.run(module) -> Report` — calls `compute(PARAMS)`, `build(geom)`, runs numerical assertions + mechanical gate, renders `figures/out/<name>.svg/.png`, prints diagnostics. Figure module contract: `CLAIM: str`, `PARAMS: dict`, `compute(p)`, `build(g) -> Scene`, `assertions(g)`.

Steps: failing test (a toy figure module runs end-to-end, produces files, clean report) → implement → pass → commit.

### Task 7: Fig 9 benchmark loop (visual iteration)

Iterate `figures/fig09_euler_spiral.py`: two-panel structure or single panel with the e^θ ray and the iθ spiral chain; labels 1, θ, θ²/2!, iθ, (iθ)²/2!, e^{iθ}, e^θ; dashed circular-arc construction; right-angle turns visible. Compare rendered PNG against the book page (Read the PNG myself each iteration). Modern restyle: semantic accents for the two series. Exit when mechanical+numerical gates clean and the figure reads correctly. Commit each meaningful iteration.

### Task 8: Readback gate

**Files:** Modify `src/figlib/gates.py`; create `src/figlib/readback.py` (prompt text + protocol doc)

Readback = spawn a context-free agent (Agent tool at execution time; `figcheck` prints instructions when run headless) that sees only the PNG and answers: "State in one sentence the mathematical claim this figure makes." Compare against CLAIM (semantic match judged by the reviewer agent given both sentences ONLY after producing its own readback). Record verdict in `figures/out/<name>.readback.md`.

Steps: run on Fig 9 → record → iterate figure if it fails → commit.

### Task 9: figcheck CLI

**Files:** Create `src/figlib/cli.py`; register `[project.scripts] figcheck = "figlib.cli:main"`

`figcheck figures/fig09_euler_spiral.py` → runs program.run, prints gate report, exit code 1 on failures. Test: subprocess invocation on the toy figure passes; on a broken figure exits 1. Commit.
